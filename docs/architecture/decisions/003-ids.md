# ADR-003: IDs

- **Estado:** Aceptada (decisión base para iniciar la implementación)
- **Fuente:** [Plan de microservicios](../Plan-Microservicios-WeRide.md), sección 3

## Decisión

Los IDs externos son strings opacos. Se conservan IDs y tipos existentes en la base que sea dueña; consumidores no convierten un ID remoto a Long. Token: sub = ID estable de cuenta como string y preferred_username = username.

## Consecuencias

Puede requerirse adaptar respuestas y claims en un corte coordinado. No migrar todos los IDs a UUID solo por uniformidad.
