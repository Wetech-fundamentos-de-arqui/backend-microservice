# ADR-007: API

- **Estado:** Aceptada (decisión base para iniciar la implementación)
- **Fuente:** [Plan de microservicios](../Plan-Microservicios-WeRide.md), sección 3

## Decisión

Mantener paths, JSON y códigos que consume el frontend en /api/v1. Gateway enruta esos paths al servicio dueño. Nuevos paths usan kebab-case plural; no cambiar frontend como parte de la extracción sin PR coordinado.

## Consecuencias

Se publica un mapa de rutas validado contra Angular antes de enrutar. Alias antiguos solo se retiran con evidencia de que no hay consumidores.
